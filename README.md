# Sistema Integral de Gestión de Clientes, Servicios y Reservas

## Descripción
Aplicación desarrollada en Python para la empresa ficticia Software FJ. Permite gestionar clientes, servicios y reservas mediante programación orientada a objetos.

## Funcionalidades
- Registro y validación de clientes.
- Gestión de diferentes tipos de servicios.
- Creación, confirmación y cancelación de reservas.
- Cálculo de costos con descuentos e impuestos.
- Manejo de excepciones personalizadas.
- Registro de eventos y errores.

## Tecnologías
- Python 3.
- Programación orientada a objetos.
- Manejo de excepciones.
- Registro de eventos mediante archivos de log.

## Ejecución
Ejecutar el archivo `main.py` desde Python.
